# Specs Directory

This directory contains all specifications and task tracking for the hackathon project.

## Files (created during hackathon)

- `PROBLEM_SPEC.md` — Analyzed problem statement with requirements breakdown
- `ARCHITECTURE.md` — Data models, API design, frontend component plan
- `TASKS.md` — Atomic task checklist with progress tracking

## How to Use

1. Paste the problem statement → `PROBLEM_SPEC.md` gets created
2. Architecture is designed → `ARCHITECTURE.md` gets created
3. Work begins → `TASKS.md` tracks every task with checkboxes

This follows the **GSD (Get Shit Done)** methodology:
> Spec → Plan → Build (atomic) → Verify → Commit → Repeat
